# EverSmile — Motion Edition

Responsive demo dental-clinic website built with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in your browser. Internet is needed for the demo’s Google Fonts and Unsplash photos.

## Features
- Scroll-triggered reveal animations with staggered service/team cards
- Desktop parallax hero, floating photography and appointment-section shapes
- Animated ticker, scroll progress bar, hover effects and motion easing
- Reduced-motion support, mobile animation safeguards, responsive layout
- Working menu, FAQs, testimonial slider and appointment email draft modal

## Customize before launch
All contact details, team members, statistics, testimonials and brand are placeholders. Replace images with properly licensed photographs of the actual clinic, update real service offerings, and set the correct clinic email in `script.js`. Booking currently prepares an email draft; it does **not** submit appointments to a backend.
